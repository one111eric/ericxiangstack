## Overview

A growing set of small, focused tools that run entirely in your browser - no
data leaves your device. Each tool is a self-contained React island so pages
stay fast and only load what they need.

## Available now

- **Unit Converter** - length, mass, temperature, and data sizes.

## On the roadmap

- JSON formatter, Base64 encode/decode, timestamp converter, and a color
  converter.
