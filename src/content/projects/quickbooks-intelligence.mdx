## Overview

<Image src={qboAgent} alt="QBO Intelligence" width={500} />

QBO Intelligence is the main user-facing AI agent for Intuit Quickbooks Online. I worked on multiple aspects of this project, including:

- Building File Upload and Download functionality for the agent to do financial analysis.
- Building code generation and code execution sandbox for the agent.
- Integrating charts and graphs into the agent's responses.
- Agent evaluation framework.
- Tool calling orchestration.
- Long term memory and personalization.
